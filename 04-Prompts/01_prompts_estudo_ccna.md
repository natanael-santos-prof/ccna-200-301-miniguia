# Prompts Úteis para Estudo de CCNA com IA

Este arquivo reúne os melhores comandos enviados para Inteligências Artificiais para auxiliar na criação de simulados, explicações de conceitos e scripts de rede.

### 1. Prompt para Criar Questões de Simulado
> **Comando:** "Atue como um instrutor oficial da Cisco focado no exame CCNA 200-301. Crie 3 questões de múltipla escolha inéditas e de nível difícil sobre o protocolo OSPF (Área 0 e Estados de Vizinhança). Não me dê as respostas de imediato, espere eu responder para depois corrigir e explicar detalhadamente cada alternativa."

### 2. Prompt para Explicar Conceitos Complexos
> **Comando:** "Explique o conceito de máscara curinga (wildcard mask) usada no OSPF e em ACLs da Cisco. Use uma analogia simples e cotidiana para quem está começando na área de redes e mostre um exemplo prático de conversão bit a bit."

### 3. Prompt para Gerar Cenários de Laboratório (Troubleshooting)
> **Comando:** "Gere um cenário fictício de problema de rede (troubleshooting) no Cisco Packet Tracer envolvendo VLANs e Troncos (Trunk). Descreva os sintomas do problema, o que os computadores estão exibindo e me dê pistas textuais passo a passo para que eu possa descobrir qual comando de configuração está errado nos Switches."

### 4. Prompt para Revisão de Códigos de Automação
> **Comando:** "Analise este script Python que utiliza a biblioteca Netmiko para enviar comandos para um switch Cisco. Verifique se existem boas práticas de segurança (como ocultar a senha) e adicione tratamento de exceções para caso o dispositivo esteja offline."
