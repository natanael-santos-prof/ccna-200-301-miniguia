# Guia Rápido de Comandos CCNA

### 1. Comandos de Verificação (Show)
* `show ip interface brief` - Verifica o status das interfaces e IPs.
* `show running-config` - Mostra a configuração atual em execução.
* `show ip route` - Exibe a tabela de roteamento do dispositivo.

### 2. Configurações Básicas
* `enable` - Entra no modo privilegiado.
* `configure terminal` - Entra no modo de configuração global.
* `interface gigabitethernet 0/0` - Entra na configuração da interface.
* `ip address 192.168.1.1 255.255.255.0` - Define o endereço IP.
* `no shutdown` - Ativa a interface.
