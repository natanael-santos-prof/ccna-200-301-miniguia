# Prompts Avançados: Automação e Memorização

Este arquivo contém comandos focados em transformar a IA em um gerador de automação de redes e um assistente de memorização espaçada.

### 1. Prompt para Criar Flashcards (Estilo Anki)
> **Comando:** "Com base nos tópicos oficiais do CCNA 200-301, crie uma lista de 5 flashcards no formato 'Frente (Pergunta)' e 'Verso (Resposta Curta)'. Foque em conceitos de decoreba obrigatórios para a prova, como os timers do OSPF, portas de protocolos comuns (SSH, HTTPS, NTP) e as distâncias administrativas padrões da Cisco."

### 2. Prompt para Traduzir Cenários de Redes em Python
> **Comando:** "Eu tenho o seguinte cenário de rede física: preciso alterar o banner MOTD de 10 switches Cisco Catalyst que estão na mesma sub-rede. Crie um script em Python usando a biblioteca Netmiko que leia os IPs de um arquivo de texto separado e aplique a configuração de forma automática e segura em todos eles."

### 3. Prompt para Explicar Mensagens de Erro (Syslog)
> **Comando:** "Vou te mandar uma mensagem de log do IOS da Cisco que peguei no terminal do meu roteador. Analise os códigos e me explique exatamente o que gerou esse evento, qual a gravidade dele (nível do Syslog) e qual comando devo rodar na linha de comando para resolver a falha: `%LINK-3-UPDOWN: Interface GigabitEthernet0/1, changed state to down`"

### 4. Prompt para Simular Entrevista Técnica de Emprego
> **Comando:** "Quero que você atue como um gerente de engenharia de redes sênior aplicando uma entrevista técnica para uma vaga de Analista de Redes Júnior (focada em CCNA). Faça uma pergunta técnica por vez sobre protocolos de roteamento ou switching. Aguarde minha resposta antes de mandar a próxima. Ao final de 3 perguntas, me dê um feedback construtivo."
